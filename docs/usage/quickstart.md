# Quickstart with example data

To quickly see some example data, you can download [this dataset from Zenodo](https://zenodo.org/records/19107066). Download the `kiye_dataset_parquet.zip`. On the `aurora-app`, go to the **Database** tab, click the **Upload** button, drag and drop the `.zip` file, scroll to the bottom and press `Confirm`.

The **Database** samples table should now show the uploaded samples.

To view the data, you can select rows in the samples table and press **View**, or go to the plotting tabs and select the samples in the menus on the left.
